# 微动效增强计划

> 目标：用细腻的微动效提升整体体验的「丝滑感」，不引入额外依赖，纯 CSS + 原生 JS 实现。

---

## 现状

目前动效很少——只有 Lightbox 缩放、Toast 弹出、侧边栏展开、文章卡片 hover 缩放 4 种。
页面切换、内容加载、滚动浏览时几乎没有动态感。

---

## 计划：分 4 层递进

### 第一层：入场动效（页面内容加载时）

| # | 位置 | 效果 | 说明 |
|---|------|------|------|
| 1 | 知识点页（TopicPage）Hero 卡片 | fadeInUp | 标题、概要依次淡入上移 |
| 2 | 知识点内容块 | staggered fadeInUp | 每个 KP 块滚动到视口时淡入，带 stagger 延迟 |
| 3 | 首页 Section 卡片 | staggered fadeIn | 各板块卡片依次出现 |
| 4 | 文章列表页卡片 | staggered fadeInUp | 文章卡片逐个淡入 |
| 5 | 文章详情页 | fadeIn | 正文区域整体淡入 |
| 6 | 名人堂页面 | staggered fadeIn | 运动员卡片依次出现 |

**实现方式：** IntersectionObserver + CSS class 切换，零依赖。

### 第二层：交互反馈（hover / click / focus）

| # | 位置 | 效果 | 说明 |
|---|------|------|------|
| 7 | 所有卡片（文章卡、Section 卡、KP 卡） | hover 微上移 + 阴影加深 | `translateY(-2px)` + shadow 变化 |
| 8 | 按钮和可点击元素 | active 缩放 | 点击瞬间 `scale(0.97)` 再恢复 |
| 9 | 侧边栏 TOC 当前项高亮 | 左边框滑动指示器 | 绿色指示条平滑移动到 active 项 |
| 10 | 标签（tag）hover | 背景色渐变 | 平滑过渡到 hover 色 |
| 11 | 面包屑箭头 | hover 微右移 | 箭头 `translateX(2px)` |

### 第三层：滚动驱动效果

| # | 位置 | 效果 | 说明 |
|---|------|------|------|
| 12 | Header | 滚动变化 | 向下滚时 header 微缩 + 加毛玻璃背景 |
| 13 | 知识点分隔线 | 渐显 | 滚动到位时分隔线从中间向两边展开 |
| 14 | 文章正文图片 | 视差微移 | 滚动时图片轻微上移（parallax 2-3%） |
| 15 | 回到顶部按钮 | 出场/隐藏平滑 | 已有基础，加上 scale 弹性 |

### 第四层：页面过渡

| # | 位置 | 效果 | 说明 |
|---|------|------|------|
| 16 | 路由切换 | 淡入淡出 | 新页面 fadeIn，旧页面 fadeOut |
| 17 | 列表 → 详情 | 内容区渐入 | 从列表点进详情时内容区 slideUp |

---

## 优先级建议

**Phase 1（效果最明显，改动最小）：** #1 #2 #3 #7 #12
— Hero 淡入、KP 滚动入场、首页卡片入场、卡片 hover 提升、Header 毛玻璃

**Phase 2（交互细节）：** #4 #5 #6 #8 #9 #10
— 更多页面入场 + 按钮/TOC 反馈

**Phase 3（进阶）：** #11 #13 #14 #15 #16 #17
— 视差、分隔线动画、路由过渡

---

## 技术约束

- 纯 CSS 动画 + IntersectionObserver，不引入 Framer Motion 等库
- 所有动效 ≤ 300ms（入场）/ ≤ 150ms（交互反馈）
- `prefers-reduced-motion` 媒体查询：尊重用户系统设置
- 移动端适当减少或简化部分动效
